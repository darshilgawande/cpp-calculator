# 🧮 Simple C++ Calculator

A lightweight, command-line calculator built from scratch using C++. This project was created as a foundational exploration of basic programming concepts, control flow, and user input handling.
---

## ✨ What it does
* **Math Operations:** Handles basic addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Error Handling:** Keeps the program from crashing if someone tries to divide by zero or types in a weird operator.
* **Terminal UI:** Simple, straightforward prompts that walk you right through your calculation.

---

## 🛠️ Tech Stack & Concepts
* **Language:** C++
* **Key Concepts:** `if-else` control flow, functions, basic I/O (`std::cin` / `std::cout`)
